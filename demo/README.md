# Proxie Robot Bridge Demo

![Proxie Robot Bridge Demo](demo.gif)

This GIF demonstrates the bridge operating against the real, public GitHub Pages
deployment at:

**https://kush-dabade.github.io/proxie-devops-assignment/**

## What the demo shows

- **Browser → Python**: live robot-state messages generated by the hosted page
  reach the local Python process in real time.
- **Python → Browser**: commands entered into the Python terminal control the
  robot running on the hosted page.
- The Chrome extension and a local WebSocket server together form the bridge
  connecting the two sides.
- The hosted page itself remains a static HTML/Three.js application — all
  bridging happens outside of it, via the extension and local server.

## What to look for

- The Chrome address bar showing the public URL above (not `localhost` or `file://`).
- The Python terminal showing `Connected` and streaming live robot-state updates.
- Robot interaction in the browser producing changing state values in the terminal.
- Commands (`forward`, `stop`, `left`, `right`, `run`) typed in the Python
  terminal visibly moving/turning/running/stopping the robot in the browser.
